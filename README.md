# Softwareentwicklung (SWD) – Wirtschaftsingenieurwesen, WS 2026/27

Willkommen! Dieses Repository gehört zur Vorlesung **Softwareentwicklung (SWD)** im
**3. Semester Wirtschaftsingenieurwesen** an der **Technischen Hochschule Ingolstadt (THI)**.

## Worum geht es?

Hier finden Sie den gesamten Code, den ich während der Vorlesungen live schreibe.
Nach jeder Vorlesung wird das Repository aktualisiert, sodass Sie alle Beispiele
nachlesen, ausprobieren und weiterentwickeln können.

## Struktur

- Beispiele aus den einzelnen Vorlesungen liegen im Hauptverzeichnis bzw. in
  Ordnern pro Vorlesung (z. B. `VL2/`).

## Code herunterladen

```bash
git clone https://github.com/LOMA-AImotion/swd_wi_ws2627.git
```

Um später neue Inhalte zu bekommen, reicht im Repository-Ordner:

```bash
git pull
```

Alternativ können Sie über **Code → Download ZIP** auf GitHub alles als ZIP-Datei herunterladen.

## Tipp

Der Code ist live in der Vorlesung entstanden und nicht immer perfekt – das ist Absicht.
Probieren Sie die Beispiele selbst aus, verändern Sie sie und schauen Sie, was passiert.
So lernt man Programmieren am besten!
